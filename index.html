Devin Balance

Десктоп-приложение в трее: баланс Devin On-demand и остановка активных сессий. Версия 1.0.1 · сборка 260626_1131 (Go, один файл, без webview).

Windows 10/11, 64-bit. Установщик: ярлык в «Пуск», иконка, опция автозапуска.

Что делает

  • Показывает остаток On-demand-баланса прямо на иконке в трее (бейдж становится красным при пересечении порога).
  • Меню: список активных сессий, «Остановить все» (с подтверждением в два клика), порог, автостоп, режим остановки, звук при срабатывании порога и автозапуск при старте системы.
  • Авто-получение токена: на странице настроек кнопка-закладка — нажмите её на app.devin.ai, и токен с Org ID сами прилетят в приложение (без копирования). Баланс подтянется автоматически.
  • Авторизация без webview: API-ключ (apk_user_…) для списка/остановки сессий + опциональный токен сессии для баланса. Вводятся один раз на странице настроек (открывается из меню в браузере).
  • Один статический бинарник ~6–9 МБ, без Python и без встроенного браузера.

Установка

Windows: запустите DevinBalance_1.0.1-Setup.exe (ставится без прав администратора, в профиль пользователя). Если SmartScreen предупреждает («неизвестный издатель») — «Подробнее» → «Выполнить в любом случае» (сборка без подписи).

Linux:

unzip DevinBalance_1.0.1-linux.zip
chmod +x devin-balance-guard
./devin-balance-guard

Нужна среда с системным треем (AppIndicator/StatusNotifier). На GNOME может потребоваться расширение AppIndicator.

macOS: сборка временно недоступна — добавим, когда обновится квота сборки.

Обновление

Версия публикуется в latest.json. Возвращайтесь сюда и скачивайте свежую сборку в любой момент.

Сборка 260626_1131: устойчивое получение баланса при антивирусе/прокси/VPN. При таймауте приложение автоматически повторяет запрос по HTTP/1.1 (частая причина «в браузере работает, а приложение висит» за перехватом HTTPS). В разделе «Сеть» появилась кнопка «Проверить соединение» — пошаговая диагностика (DNS → TCP → TLS → запрос баланса), показывает, где именно рвётся соединение. На странице настроек устаревший баланс больше не выдаётся за актуальный: при сетевой ошибке он честно помечается «(устарел)» с текстом ошибки.

Сборка 260626_1021: баланс следует за активным аккаунтом в браузере. Если сменить аккаунт в браузере, приложение само переключает связку токен+Org на текущий аккаунт и сбрасывает кэш баланса — значение больше не «застывает» на прошлом аккаунте (даже когда старый токен ещё валиден и запрос успешно отдаёт прежний баланс). Введённый вручную токен при этом не перетирается.

Сборка 260626_0902: стабильное получение On-demand баланса. Значение больше не «застывает»: устаревшее число помечается и ограничено по времени, а при стойком рассинхроне токена/Org после смены аккаунта связка сбрасывается и подхватывается заново из браузера.
