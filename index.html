Devin Balance Guard

Расширение Chrome (MV3): показывает остаток баланса Devin и автоматически останавливает активные сессии при падении баланса ниже порога. Этот сайт раздаёт подписанную сборку и обслуживает автообновление.

Установка без «режима разработчика»

Chromium-браузеры (Chrome, Edge, Brave, Opera, Yandex, Chromium) разрешают одношаговую установку self-hosted расширения только через корпоративную политику ExtensionInstallForcelist. Готовые файлы политики — в папке policies/.

Linux (Chrome)

sudo mkdir -p /etc/opt/chrome/policies/managed
sudo curl -fsSL https://mikhailg517.github.io/devin/policies/linux/devin-balance-guard.json \
  -o /etc/opt/chrome/policies/managed/devin-balance-guard.json
# полностью перезапустить Chrome

Windows (все Chromium-браузеры)

Скачайте devin-balance-guard.reg — один файл прописывает политику сразу для Chrome, Edge, Brave, Opera, Yandex и Chromium. Запустите его от имени администратора (ПКМ → «Слияние» → подтвердите UAC; запись в HKLM без админ-прав молча не сработает) и полностью перезапустите браузер. Проверка: <browser>://policy → «Перезагрузить политики».

macOS (Chrome)

sudo cp com.google.Chrome.ExtensionInstallForcelist.plist \
  /Library/Managed\ Preferences/com.google.Chrome.plist
# полностью перезапустить Chrome

Автообновление

Браузер периодически опрашивает updates.xml и автоматически ставит новую версию, как только она опубликована здесь — действий от пользователя не требуется.
