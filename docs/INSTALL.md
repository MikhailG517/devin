репозитория `devin`. После установки расширение обновляется автоматически.

## Распакованная установка (для разработки)

Ниже — установка как «распакованное» (developer mode), для локальной разработки.
Шаги одинаковы для всех Chromium-браузеров — отличается только адрес страницы
расширений.

## 1. Получить файлы расширения

Есть три варианта:

| Вариант | Что использовать |
| --- | --- |
| Готовый билд (рекомендуется) | Папка `release/devin-balance-guard/` из репозитория |
| ZIP-архив | Распаковать `release/devin-balance-guard-<version>.zip` в любую папку |
| Из исходников | Папка `extension/` как есть |

> **Важно:** ZIP-архив нужно **распаковать**. При установке выбирается папка с
> `manifest.json`, а не сам архив.

## 4. Загрузить распакованное расширение

1. Нажмите **«Загрузить распакованное расширение»** (Edge: «Загрузить
   распакованное»).
2. Выберите папку с `manifest.json`:
   - `release/devin-balance-guard/` (готовый билд), или
   - `extension/` (исходники).
3. Иконка расширения появится в тулбаре.
4. Закрепите расширение: значок пазла → «Закрепить» рядом с Devin Balance Guard.

## 5. Первоначальная настройка

### 5.1 Войти в Devin

Откройте `https://app.devin.ai` в том же браузере и убедитесь, что вы
залогинены. Это необходимо для автоматического режима (API-ключ и баланс
считываются через ваш вход).

### 5.2 Открыть настройки расширения

Два способа:
- Кликнуть иконку расширения → нажать шестерёнку (⚙) в попапе.
- ПКМ по иконке расширения → «Параметры».

### 5.3 Настроить API-ключ

| Режим | Описание | Что нужно |
| --- | --- | --- |
| **Автоматически** (по умолчанию) | Расширение само получает ваш личный ключ `apk_user_…` через текущий вход в `app.devin.ai`. | Быть залогиненным в `app.devin.ai`. |
| **Вручную** | Вы вставляете ключ вручную. | Ключ `apk_user_…` из Devin: **Настройки → Devin API**. |

### 5.4 Настроить источник баланса

| Источник | Описание | Что нужно |
| --- | --- | --- |
| **Баланс On-demand** (по умолчанию) | Остаток On-demand usage в USD. | Быть залогиненным в `app.devin.ai` (ключ не нужен). |
| **Командный баланс кредитов** | Enterprise-баланс кредитов. | Сервисный ключ с правом **Billing Read**. |
| **Ручной бюджет** | Фиксированное число, заданное вручную. | Ввести число. |

### 5.5 Настроить параметры остановки

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Порог остановки** | Значение баланса, при котором срабатывает авто-остановка. | `5` |
| **Направление** | `Ниже порога` — стоп, когда баланс < порога. `Выше порога` — стоп, когда значение > порога. | `Ниже порога` |
| **Авто-остановка** | Включить/выключить автоматическую остановку. | Включена |
| **Сколько сессий** | Лимит остановки. `0` = все активные сессии. | `0` (все) |
| **Интервал опроса** | Как часто проверять баланс (в минутах, минимум 0.5). | `1` |

### 5.6 Сохранить и проверить

1. Нажмите **«Сохранить»**.
2. Нажмите **«Проверить подключение»**.
3. Ожидаемый результат:
   - `Ключ: получен автоматически (OK)` — API-ключ работает.
   - `Сессии: OK (найдено N)` — список сессий доступен.
   - `Баланс On-demand: OK ($XX.XX)` — баланс считан.

## 6. Использование

### 6.1 Попап (основной экран)

- **Баланс**: большое число с символом `$` (для On-demand).
  - Синяя карточка — норма.
  - Красная карточка — баланс пересёк порог.
  - Жёлтая карточка — ошибка (нет входа, сетевая проблема).
- **Порог**: можно изменить прямо в попапе (поле с числом).
- **Авто-остановка**: тумблер вкл/выкл прямо в попапе.
- **Обновить**: немедленно опросить баланс и сессии.
- **Остановить все**: вручную остановить активные сессии (с учётом лимита).
- **Список сессий**: активные сессии с ссылками на Devin.
- **Время последней проверки**: внизу попапа.

### 6.2 Бейдж иконки

Число на иконке расширения в тулбаре:
- Показывает текущий баланс (округлённый).
- Синий фон — норма, красный — баланс пересёк порог.

### 6.3 Уведомления

При авто-остановке расширение показывает системное уведомление:
`"Баланс X ниже Y. Остановлено Z из W активных сессий."`

## 7. Обновление расширения

### Обновление без смены версии
- Внесите изменения в файлы.
- Нажмите **↻ (Reload)** на карточке расширения в `chrome://extensions`.

### Обновление на новую версию
1. Пересоберите: `./scripts/build-release.sh`.
2. Замените папку `release/devin-balance-guard/` на новую.
3. Нажмите **↻ (Reload)** (или удалите расширение и загрузите заново).

## 9. Частые проблемы и решения

| Проблема | Причина | Решение |
| --- | --- | --- |
| «Manifest file is missing or unreadable» | Выбран ZIP-архив или не тот уровень папки. | Выберите распакованную папку с `manifest.json`. |
| Баланс показывает `—` | Не залогинены в `app.devin.ai` или content-скрипт ещё не передал данные. | Откройте `app.devin.ai`, подождите 5-10 секунд, нажмите «Обновить» в попапе. |
| «Не указан API-ключ» | Режим `manual`, ключ не введён. | Введите ключ в настройках или переключитесь на `auto`. |
| «Неверный API-ключ» | Ключ не имеет доступа к API v1. | Используйте личный ключ `apk_user_…` (не сервисный). |
| «Сессия Devin недействительна» | Токен истёк. | Перезагрузите страницу `app.devin.ai` (или выйдите и войдите заново). |
| Ключ не получен автоматически | Первый вход — ещё нет вкладки `app.devin.ai`. | Откройте любую страницу `app.devin.ai`. |
| Уведомления не приходят | Уведомления отключены в ОС или в настройках Chrome. | Проверьте настройки уведомлений ОС и `chrome://settings/content/notifications`. |

## 10. Безопасность и конфиденциальность

- Все учётные данные хранятся **только** в `chrome.storage` на вашем устройстве.
- Данные отправляются **только** на хосты Devin:
  - `api.devin.ai` — публичный API (сессии).
  - `app.devin.ai` — внутренний API (баланс, ключ).
  - `server.codeium.com` — enterprise-биллинг (только если выбран источник `team`).
- Третьим лицам **ничего не передаётся**.
- Content-скрипт работает **только** на `app.devin.ai`.

> **API-ключ** нужен только для **остановки** и **списка** сессий.
> Для **чтения баланса** On-demand достаточно вашего входа в браузере.
