# Установка Devin Balance Guard (десктоп)

Скачайте ZIP под свою ОС со страницы
<https://mikhailg517.github.io/devin/> и распакуйте.

Сборки **без подписи** (Apple Developer / Authenticode стоят денег), поэтому при
первом запуске ОС может предупредить — это нормально, см. ниже как обойти.

## Windows 10/11 (64-bit)

1. Распакуйте `devin-balance-guard-windows.zip`.
2. Запустите `devin-balance-guard.exe`.
3. Если SmartScreen показывает «Система Windows защитила ваш компьютер» →
   **«Подробнее»** → **«Выполнить в любом случае»**.

Иконка появится в системном трее (область уведомлений, рядом с часами).

## macOS

1. Распакуйте `devin-balance-guard-macos.zip` — внутри `Devin Balance Guard.app`.
2. Перенесите его в «Программы» (необязательно).
3. Первый запуск: **правый клик (Ctrl-клик) по приложению → «Открыть» → «Открыть»**.
   Это обходит Gatekeeper для неподписанного приложения (обычный двойной клик
   в первый раз будет заблокирован).

Это приложение меню-бара (`LSUIElement`): иконка появляется в строке меню
сверху, без значка в Dock.

## Linux

```bash
unzip devin-balance-guard-linux.zip
chmod +x devin-balance-guard
./devin-balance-guard
```

Нужны системные библиотеки GTK3 + WebKit2GTK 4.1 (на большинстве десктопов уже
есть). На Debian/Ubuntu при необходимости:

```bash
sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0 gir1.2-webkit2-4.1 \
  gir1.2-ayatanaappindicator3-0.1
```

Иконка появляется в системном трее (зависит от окружения рабочего стола; для
GNOME может понадобиться расширение AppIndicator).

## Первый вход

1. Откройте меню иконки в трее → **«Войти в Devin…»**.
2. В открывшемся окне войдите в `app.devin.ai`, как обычно (GitHub / Google /
   email). Токен считывается автоматически — копировать ничего не нужно.
3. Баланс и список сессий появятся в меню. Дальнейшие запуски — без повторного
   входа (cookies сохраняются).

## Обновление

Приложение само сверяется с `latest.json` на этой странице и при новой версии
покажет уведомление и пункт меню **«Скачать обновление»**. Можно просто вернуться
на <https://mikhailg517.github.io/devin/> и скачать свежий ZIP.
